# 文档、工作区和多标签

用户可以新建或打开 Markdown/HTML/Word 文档，在工作区文件树中浏览文件，在多标签之间切换，并通过显式保存或另存为把变更写回本地文件。

## 子功能

- `document-new-open` 新建文档或打开支持的文档类型。
- `workspace-tree` 选择工作区并从文件树按需打开文档。
- `document-save` 保存当前文件或另存为新文件。
- `tab-dirty` 在多标签之间保留各文档内容和未保存状态。

## 用户视角入口

- 工具栏 `新建文档`、`打开文件`、`打开文件夹`、`保存当前文件`。
- 保存菜单中的 `另存为新文件`。
- 快捷键 `Ctrl/Cmd+O`、`Ctrl/Cmd+Shift+O`、`Ctrl/Cmd+S`、`Ctrl/Cmd+Shift+S`。
- 将支持的文件拖入应用窗口。

## 用 exe-CDP harness 驱动

前置条件：

- 使用真实 exe 和一次性临时夹具目录；夹具目录必须位于证据目录之外，并在运行结束后由配方删除。
- 原生打开/保存/文件夹选择器需要当前宿主提供桌面 UI 自动化；没有这个条件时保持未验证，不用 React 测试代替。
- 当前 `verify:exe-core` 已用文件关联参数打开一次性 Markdown 夹具，编辑后用 `Ctrl+S` 回读磁盘字节，并创建了独立未命名标签；原生文件夹选择器和多文件切换仍未执行。

- **新建入口。** 在真实 exe 中选择 `新建文档`；预期出现 `未命名.md` 标签、编辑器可见，状态栏仍显示未保存。当前套件已执行并记录标签数量。
- **打开工作区。** 选择 `打开文件夹`，在原生文件夹选择器选一次性夹具目录；预期出现 `workspace-sidebar`/文件树和夹具文件名。目录选择器不是网页 DOM，必须把选择动作和目录路径记录到证据。
- **打开文件。** 选择 `打开文件`，在原生文件选择器选夹具 Markdown；预期编辑器显示文件内容、状态栏显示文件路径，且从文件字节读取的内容与第二个可见视图一致。
- **保存变更。** 通过 `.cm-content` 或写作视图输入内容，选择 `保存当前文件`；预期保存状态从 `正在保存` 到 `已保存`，再用 PowerShell `Get-Content -Raw <fixture>` 或 Rust 读取命令核对实际字节，不能只看 toast。
- **多标签切换。** 打开第二个夹具文件，再选择 `role=tab` 的文件名；预期每个标签恢复自己的内容和 `未保存` 状态，切换期间不应静默丢弃脏文档。
- **回滚夹具。** 关闭标签或退出验证前，确认夹具文件由本次运行创建；删除夹具目录并保留截图、ARIA、文件字节摘要和退出状态。

## 陷阱

- 原生文件对话框不能用 CSS 选择器或浏览器 Tab 序描述；没有桌面驱动时应报告受阻/未验证。
- `打开文件夹` 只改变工作区根目录，不应预期所有文件自动变成标签页。
- `Ctrl/Cmd+S` 对未保存文档会继续打开保存对话框；必须完成路径选择后再验证字节。
- 自动保存默认关闭；不要把输入后状态变化当成自动写盘。
- 不能删除用户已有目录或同名文件；夹具必须由本次运行创建并可验证归属。
